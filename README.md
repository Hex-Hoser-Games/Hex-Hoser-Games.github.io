# Hex & Hoser Games

The official website for Hex & Hoser Games, a Canadian independent game studio.

## Local preview

This is a dependency-free static site. Open `index.html` directly, or serve the folder with any local HTTP server.

```sh
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publishing

The site is ready for GitHub Pages. In the repository settings, choose **Pages**, deploy from the main branch, and select the repository root.

## Updating content

- Studio and game information: `index.html`
- Support instructions and contact: `support.html`
- Privacy disclosures: `privacy-policy.html`
- Shared colours, type, and layouts: `styles.css`

Before publishing a new game or SDK integration, review the privacy policy and update it to match the data the product actually collects.
